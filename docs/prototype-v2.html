Example investigation

User: Why was repair WO-10482 delayed?

Agent: The first appointment ended in no access on 11 Sep. It was rebooked for 13 Sep and completed at 15:41. No contractor rejection was recorded.

work_orders v1 appointments v1 manifest run_0915_0200

Read-only first. State changes remain blocked.
Deterministic obligations stay deterministic. AI does not redefine deadlines or entitlements.
Tenant-scoped auth + audit. Agent inherits the caller's access boundary.
Human approval later. Sensitive write tools require explicit confirmation.
